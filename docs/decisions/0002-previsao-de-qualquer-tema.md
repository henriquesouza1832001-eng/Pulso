# 0002 — O PULSO prevê qualquer tema, como probabilidade calibrada

**Contexto.** O documento inicial proibia previsões políticas ("quem vai ganhar", "chance de golpe") e limitava o produto a antecipar anomalias. O objetivo do produto é ser um "Pizza Index do Brasil": antecipar acontecimentos a partir de sinais públicos.

**Decisão.** Qualquer pergunta com resposta verificável por informação pública pode virar uma previsão, inclusive política e eleitoral. Em troca, toda previsão é: probabilidade com incerteza, rotulada como previsão, ligada às evidências e ao método, registrada antes do resultado e pontuada depois (Brier/calibração), com status EXPERIMENTAL até calibrar. A previsão nunca eleva sozinha o nível de alerta PULSO 4–5.

**Consequências.** Nasce uma tabela e uma API de `forecasts`; o histórico de acertos passa a fazer parte do produto. Previsões eleitorais exigem revisão jurídica (pesquisas registradas, legislação eleitoral) antes de publicação pública. A regra do AGENTS.md foi atualizada.
